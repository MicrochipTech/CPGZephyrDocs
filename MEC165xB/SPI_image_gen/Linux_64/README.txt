Microchip SPI Image Generator for MEC165xB SoC's

Host OS: Linux x86_64
Artifact name: mec165xB_spi_gen_linux_x86_64
Configuration file: spi_cfg.ini

Refer to release.txt in parent directory (Windows version)

Optional command line parameters:
-i string
	SPI image configuration file in Go gcfg format
	
-m string
	SPI flash image binary file to merge firmware images into
	
-o string
	File name of generated SPI flash binary (default is "spi_image.bin")
